# add-api-route Changelog

All notable changes to this skill will be documented in this file.

## [1.1.0] - 2026-02-03

### Added (Journey-driven: multi-language-support)
- Third-party API integration pattern (alternative to backend proxy)
- Server-side in-memory caching pattern for external APIs
- In-flight request deduplication to prevent duplicate API calls
- Cache pruning to prevent memory issues
- When-to-use guidelines for third-party API pattern

## [1.0.0] - 2026-02-02

### Initial Release
- API route scaffolding with authentication via callApi
- Support for static and dynamic routes
- Cache header configuration guidance
- Error handling patterns
- Optional service function creation
